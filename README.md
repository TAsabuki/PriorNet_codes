Sample Code for Asabuki & Fukai (2024)

This repository contains the Python code to reproduce the main results in the following publication:

Asabuki, T. & Fukai, T. (2024). Predictive learning rules generate a cortical-like replay of probabilistic sensory experiences. eLife.

Requirements

- Python 3.x
- numpy
- scipy
- matplotlib
- numba
- tqdm
